## 읽는 순서

1. **가드 4겹** — 무엇을 실행할 수 있는가 (경계의 바깥)
2. **외부 팩 격리** — 신뢰할 수 없는 확장이 서버를 어떻게 못 멈추게 하는가
3. **에이전트 생성 파서 샌드박스** — 신뢰할 수 *없는* 코드는 어떻게 격리하는가
4. **의미 diff** — 결과를 어떻게 읽고 비교하는가
5. **예산 최종 상한 검증** — 결과를 어디까지 내보내는가

## 형식

각 ADR 은 아래 목을 가진다.

- **맥락** — 무엇이 문제가 되는가. 결정의 전제가 여기 있다.
- **결정** — 무엇을 하는가. 규칙으로 적는다.
- **이 결정이 주는 것과 주지 않는 것** — **경계가 어디인지.** 이 절이 없으면 결정이 방어선보다 커 보인다.
- **대안** — 왜 이것을 골랐고 왜 다른 것은 안 골랐는가.
- **결과** — 무엇이 바뀌고, 무엇이 남는가.

"주지 않는 것"을 생략하지 않는다. 경계를 솔직히 적는 문서가 나중에 그 경계 밖으로 나가지 않게 한다.
